# Student Performance Prediction

## Project Overview

This project uses Machine Learning to predict students' final academic performance based on demographic, social, and academic factors.

The goal is to explore student data, identify important features, train machine learning models, and evaluate their prediction performance.

## Dataset

- Source: UCI Machine Learning Repository
- Dataset: Student Performance
- File: `student-mat.csv`
- Records: 395 students
- Features: 33 columns
- Target variable: `G3` (final grade)
